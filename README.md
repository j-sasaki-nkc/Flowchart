# Flowchart
## TestCaseのエラー処理設定

TestCaseのプロパティでは、実行内容に応じてエラー処理方法を設定すること。

```mermaid
flowchart TD
    A[エラー発生] --> B{同階層の<br>SmartFolderを<br>実行する必要があるか？}

    B -- はい --> C["次のテストケースに移動"]

    B -- いいえ --> D{エラー発生を<br>想定した<br>テストか？}

    D -- はい --> E["次の繰り返しに移動して続行"]

    D -- いいえ --> F["次の親テストケースに移動"]
```
